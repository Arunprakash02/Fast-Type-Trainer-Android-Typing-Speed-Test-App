# Fast Type Trainer ⌨️

Fast Type Trainer is an Android application designed to help users practice and improve their typing speed and accuracy.

The application provides a simple and user-friendly environment where users can practice typing and track their performance.

## 🚀 Features

* ⌨️ Typing speed practice
* 🎯 Accuracy tracking
* ⏱️ Typing performance measurement
* 📱 Clean and simple Android UI
* ⚡ Fast and lightweight application
* 📊 Performance-based typing practice
* 🔄 Easy-to-use typing interface

## 🛠️ Tech Stack

* **Language:** Kotlin
* **UI:** XML
* **Architecture:** Android Architecture Components
* **Build System:** Gradle
* **Android Gradle Plugin:** 8.10.1
* **Compile SDK:** 36
* **Minimum SDK:** 24
* **Target SDK:** 36

### Android Libraries

* AndroidX Core KTX
* AndroidX AppCompat
* Material Components
* AndroidX Activity
* ConstraintLayout
* JUnit
* Espresso

## 📋 Requirements

Before running the project, make sure you have:

* Android Studio
* JDK 11 or compatible JDK configuration
* Android SDK 36
* Android device or emulator
* Internet connection for the initial Gradle dependency download

## 📥 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/fast-type-trainer.git
```

### 2. Open the project

Open the cloned project in **Android Studio**.

### 3. Sync Gradle

Allow Android Studio to download the required dependencies and complete the Gradle sync.

### 4. Run the application

Connect an Android device or start an Android Emulator.

Then click:

**Run ▶**

## 🧪 Testing

The project includes testing dependencies for:

* Unit testing using **JUnit**
* UI testing using **Espresso**

Run tests from Android Studio or using Gradle:

```bash
./gradlew test
```

For instrumented tests:

```bash
./gradlew connectedAndroidTest
```
